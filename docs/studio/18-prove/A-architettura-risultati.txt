== A4 file format: what from_json does with damaged or old input
   no 'version' key: KeyError: 0 -> NOT caught by open_path (OSError, ValueError only)
   version 0 (older than any migration): KeyError: 0 -> NOT caught by open_path (OSError, ValueError only)
   a building without name and footprint: TypeError: Building.__init__() missing 2 required positional arguments: 'name' and 'footprint' -> NOT caught by open_path (OSError, ValueError only)
   a sub-field whose ring is a number: accepted; later TypeError: 'int' object is not iterable
   buildings is a dict, not a list: AttributeError: 'str' object has no attribute 'items' -> NOT caught by open_path (OSError, ValueError only)
   site latitude is text: accepted; later ValueError: could not convert string to float: 'north'
   variants without the one in hand: accepted
   a newer format (7): ValueError: made by a newer Meridiana (format 7); update the program to open it -> caught by open_path
