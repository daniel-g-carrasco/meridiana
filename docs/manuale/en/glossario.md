# Interface glossary

Terms taken from `po/it.po`: Italian = `msgstr`, English = `msgid`.
Command wording and capitalisation follow the interface; descriptive headings
may add an article. Repeated terms have different meanings: Posa is Lay for
the tool and Layout for the group; Firma is Signed by for the field and
Signature for the group; Nessuno is None for a general choice and Nobody for
the signatory. Legal references and identifiers stay unchanged.
