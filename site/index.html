Meridiana

Photovoltaic design: map, building model, sun path, module layout and Italian standards.

Meridiana designs photovoltaic plants: the site on a map or an orthophoto, buildings and roofs, the module layout with the fire brigade rules, the hourly energy with every loss, the string checks, consumption and economics, and a PDF report where every number says where it comes from. No account; your projects never leave your computer.

Download for Windows Install on Linux (Flatpak) Source on GitHub

Windows: the installer needs no administrator rights; a portable zip is there too. Every file of a release is signed with minisign: the public key and how to check a download are in the code signing policy. Linux: the Flatpak, once its repository is published; until then it builds from the manifest in the sources.
